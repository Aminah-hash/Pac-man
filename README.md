# Pac-man 🎮

A classic Pac-Man arcade game developed using C++ and SFML.

## Project Description
This project recreates the classic Pac-Man game, where the player navigates through a maze while avoiding ghosts and collecting points.

## Features
- Player movement
- Maze navigation
- Ghost enemies
- Collision detection
- Score system
- Game over and winning conditions

## Technologies Used
- C++
- SFML (Simple and Fast Multimedia Library)

## Project Status
Currently under development.
